# ⚔️ Ascendia ⚔️

Aplicação web desenvolvida como MVP acadêmico para a disciplina de Tecnologia em Sistemas para Internet, utilizando arquitetura separada entre **Frontend** e **Backend**, comunicando-se via **API REST** e servida por um único servidor **Flask**.

## 🚀 Requisitos
- Python 3.8+ instalado na máquina.

## 📦 Instruções de Instalação e Execução

1. Clone ou baixe este repositório para o seu computador.
2. Abra o terminal na raiz do projeto (`LifeQuest/`).
3. Crie e ative um ambiente virtual Python:
   ```bash
   python -m venv venv
   
   # No Windows:
   venv\Scripts\activate
   
   # No Linux/macOS:
